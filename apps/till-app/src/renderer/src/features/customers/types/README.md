# Customer Types

## Future Interfaces

- `Customer`: The core domain model representing a customer entity.
- `CustomerAddress`: Represents structured address details (street, city, zip, etc.).
- `CustomerContact`: Represents contact channels (email, phone).
- `CustomerStats`: Aggregated metrics (total spend, visit count).
- `CustomerActivity`: Represents a historical event or transaction for the customer.
- `CustomerStatus`: Enum or literal union for account status (Active, Inactive, Banned).

## Rules

- Place only TypeScript type definitions and interfaces here.
- Do not include any runtime code or constants in this folder.
