# Customer Utilities

## Future Helper Utilities

- **Customer formatter:** Functions to format full names or profile summaries.
- **Phone formatter:** Functions to standardize or cleanly display phone numbers.
- **Address formatter:** Functions to concatenate address parts into a readable string.
- **Loyalty formatter:** Functions to calculate or format loyalty points.

## Rules

- Keep pure functions only.
- No React hooks, no state, no side effects.
